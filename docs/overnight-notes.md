## 能力值系統（我做的決定）

| 能力值 | 效果 |
|---|---|
| 體魄 | 生命上限 |
| 耐力 | 體力上限、少量防禦 |
| 力量 | 重武器傷害（斧、鎚、劍） |
| 敏捷 | 快武器傷害（短刀、太刀、長槍）、攻擊速度（最多 +15%） |
| 智識 | 法杖、鐮刀傷害，技能冷卻（最多 -15%） |
| 幸運 | 暴擊率（最多 +12%）、掉落稀有度升級機率 |

- 每種能力值從 **5** 開始，等級 = 六項總和 − 29（舊存檔：舊數值 + 4，**等級不變**）。
- **遞減**：前 15 點每點算 1、接下來 20 點每點 0.6、之後每點 0.2。
  - 例：力量從 5 點到 20 點 → 戰鎚攻擊 +108%；到 40 點只多一點點。
- **需求**：例如 12 級的戰鎚要力量 14、耐力 8。不夠就**不能裝備**。
  - 舊存檔身上已經裝著、但需求不夠的裝備：仍然可以用，但攻擊力只剩 60%，裝備格會顯示紅色「!」。
- 掉落的武器會**偏向你能裝備的類型**（3:1），減少一直撿到用不了的東西。

## 主線（草稿）

- **前提（暫定，可整份替換）**：「星墜之夜」，一顆星墜落後碎成七顆星核，被七隻 Boss 吞下。主角是被營火喚醒的見習魔女。石碑和鎮民的話會暗示「魔女和星星有關」，結局先標成「待續」。
